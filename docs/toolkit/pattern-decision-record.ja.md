### 障害注入

- [ ] 1つの Agent がタイムアウトする。
- [ ] 1つの Agent が不正な Schema を返す。
- [ ] 2つの Agent が競合する結論を提出する。
- [ ] メッセージまたは結果が重複配信される。
- [ ] Supervisor が深さ、幅、または予算の上限を超える。
- [ ] 高リスク操作に必要な承認がない。
- [ ] Artifact のハッシュまたはバージョンが一致しない。

### 再評価の条件

- マルチエージェントにより品質またはレイテンシが大幅に改善されない。
- 協調コストが便益を上回る。
- Supervisor / Join が主要なボトルネックになる。
- 権限、エビデンス、または状態の境界を継続的に満たせない。
- ビジネス目標、リスクレベル、またはチームの所有権が変化する。
